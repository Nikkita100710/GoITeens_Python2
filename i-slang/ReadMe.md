## 📖 Про проєкт

**Словник інтернет-сленгу** — це інтерактивна програма з графічним інтерфейсом для вивчення, керування та тестування знань англомовного інтернет- та комп'ютерного сленгу. Проєкт створено як частину дослідницької роботи учня 10-В класу Краматорського опорного закладу "Академічний".

### ✨ Основні можливості

- 🔍 **Швидкий пошук** — фільтрація слів у реальному часі
- 🔊 **Озвучення** — прослуховування англійської вимови через Google TTS
- ✏️ **Редагування** — додавання, зміна та видалення записів
- 📊 **Експорт у PDF** — формування професійного словника з кольоровою підсвіткою
- 🎯 **Інтерактивне тестування** — три рівні складності (легкий, середній, складний)
- 💾 **Резервне копіювання** — захист даних від випадкового видалення
- 🗂️ **Сортування та очищення дублікатів** — автоматична оптимізація бази

### 📊 База даних

| Рівень | Файл | Кількість слів | Опис |
|--------|------|----------------|------|
| 🟢 Легкий | `slang_ukr_easy.json` | 30 | Базові акроніми (LOL, BRB, IDK) |
| 🟡 Середній | `slang_ukr_medium.json` | 50 | Популярні неологізми (selfie, vlog) |
| 🔴 Складний | `slang_ukr_hard.json` | 300+ | Спеціалізований сленг різних спільнот |

### Варіант 1: Готовий EXE-файл (Windows) ⚡

**Найпростіший спосіб** — для користувачів, яким не потрібен Python.

#### Крок 1: Завантаження та розпакування


## 📝 Робота з базою даних (JSON)

### Структура запису

Кожен термін зберігається у JSON-форматі з такими полями:

```json
{
  "word": "LOL",
  "transcription": "[el oʊ el]",
  "meaning": "laughing out loud",
  "translation": "голосно сміюся",
  "origin": "Поширився в IRC чатах 1990-х",
  "note": "Найпопулярніший інтернет-акронім",
  "type": "Ініціалізм",
  "audio": "lol.mp3"
}
```

### Редагування словника

#### Через інтерфейс програми

1. Запустіть `i_slang.exe` або `python i_slang.py`
2. Оберіть слово зі списку
3. Натисніть кнопку **✏️ Редагувати**
4. Змініть потрібні поля
5. Натисніть **💾 Зберегти**

#### Через текстовий редактор

1. Відкрийте файл `slang_ukr_hard.json` у редакторі (VSCode, Notepad++)
2. Додайте новий запис у масив:

```json
{
  "word": "YOLO",
  "transcription": "[ˈjoʊloʊ]",
  "meaning": "you only live once",
  "translation": "живеш лише раз",
  "origin": "Популяризовано репером Drake (2011)",
  "note": "Девіз імпульсивних дій",
  "type": "Акронім",
  "audio": "yolo.mp3"
}
```

3. Збережіть файл у кодуванні **UTF-8**
4. Перезапустіть програму

> ⚠️ **Важливо:** JSON-формат чутливий до коми — останній елемент масиву НЕ повинен мати кому після `}`.

## 🎯 Модуль тестування

### Як працює тест

1. Запустіть програму `i_slang.exe` або `python i_slang.py`
2. Натисніть кнопку **🎯 Пройти тест** у головному вікні
3. Оберіть рівень складності:
   - 🟢 **Легкий** (30 слів)
   - 🟡 **Середній** (50 слів)
   - 🔴 **Складний** (300+ слів)
4. Відповідайте на 10 випадкових питань
5. Отримайте результат з детальною статистикою

### Система оцінювання

| Правильних відповідей | Оцінка |
|----------------------|--------|
| 0-3 | Треба попрацювати! 💪 |
| 4-6 | Непогано! 👍 |
| 7-8 | Чудовий результат! 🎉 |
| 9-10 | Ідеально! 🏆 Ви експерт! |

## 🛠️ Функції програми

### 1. Пошук та фільтрація
- Введіть частину слова у поле пошуку
- Список автоматично відфільтрується
- Регістр не має значення

### 2. Озвучення
- Натисніть 🔊 біля англійського значення
- Аудіо генерується через Google TTS
- Файли зберігаються у папці `audio/`

### 3. Додавання нового слова
1. Натисніть **➕ Додати слово**
2. Заповніть всі поля
3. Оберіть тип слова з випадаючого списку
4. Натисніть **💾 Зберегти**

### 4. Експорт у PDF
1. Натисніть **📄 Експорт у PDF**
2. Оберіть місце збереження
3. Отримайте професійний PDF-документ з:
   - Кольоровою підсвіткою типів
   - Українським та англійським текстом
   - Транскрипціями у квадратних дужках

### 5. Резервне копіювання
- Натисніть **💾 Backup**
- Створюється копія JSON з часовою міткою
- Приклад: `slang_ukr_hard_backup_20250116_143052.json`

## 🐛 Відомі проблеми та рішення

### Проблема: Програма не запускається (EXE)

**Рішення:**
- Переконайтеся, що всі JSON-файли та шрифти у папці з EXE
- Перевірте, чи не блокує Windows Defender
- Запустіть від імені адміністратора

### Проблема: Не працює озвучення

**Рішення:**
- Перевірте підключення до Інтернету (потрібно для Google TTS)
- Переконайтеся, що папка `audio/` існує
- Перевірте налаштування звуку Windows

### Проблема: Помилка при збереженні JSON

**Рішення:**
- Закрийте файл JSON, якщо він відкритий в іншій програмі
- Перевірте права доступу до папки
- Зробіть резервну копію перед редагуванням

### Проблема: Модуль тестування не запускається

**Рішення:**
- Переконайтеся, що файл `test_module.py` знаходиться у тій самій папці
- Запускайте тест через кнопку **🎯 Пройти тест** у головному вікні
- Перевірте, що JSON-файли рівнів складності не пошкоджені
